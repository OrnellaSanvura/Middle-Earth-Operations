Middle-Earth Operations

A C# console application that manages characters, missions, threats, and operations in a Middle-Earth themed system.

Features
Add and display characters
Add and display missions
Add threats
Start operations
Console-based menu system
Error handling using try-catch
Object-oriented programming concepts
Technologies Used
C#
.NET
Visual Studio
Object-Oriented Programming
Concepts Practised

This project was created to practise C# programming and object-oriented programming concepts such as classes, objects, inheritance, polymorphism, methods, constructors, collections, exception handling, and console input/output.

How to Run
Clone or download the repository.
Open the solution in Visual Studio.
Build the project.
Run the application.
Use the numbered menu options to interact with the system.
Project Structure

The project contains classes for characters, missions, threats, and the operations manager. The Program.cs file provides the main console menu and handles user interaction.
